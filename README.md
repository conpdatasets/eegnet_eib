# EEGManyLabs - Resting State Dataset - Eimer1996

This dataset contains raw EEG resting-state recordings (eyes open, eyes closed) in BIDS format. These data were collected as part of an EEGManyLabs replication of Eimer (1996), prior to the main replication task. Participants are healthy adults.

**Be aware:** EEG data were collected at multiple sites. Recordings have different sampling rates, channel layouts, and recording references, and have not been rereferenced. Data were cropped, trigger codes harmonized, acquisition dates changed for deidentification, and recordings exported in EDF format.

Please reference:

- https://doi.org/10.1016/j.cortex.2021.03.013
- https://doi.org/10.1016/j.cortex.2025.05.014
